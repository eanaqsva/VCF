VCF Lerntrainer Patch v16

Basis: Premium v14. Dieser Patch ersetzt Patch v15 vollständig.

Installation:
1. review-patch-v16.js neu in das Root-Verzeichnis hochladen.
2. Die vorhandene sw.js ersetzen.
3. review-patch-v15.js kann gelöscht werden.
4. Alle übrigen Dateien aus Premium v14 unverändert lassen.

Neu:
- Bei zufälliger Reihenfolge zählt die Anzeige fortlaufend von "Zufällige Frage 1 von 60" bis "Zufällige Frage 60 von 60".
- Darunter steht die tatsächliche Originalfrage, zum Beispiel "Originalfrage 37".
- Nach der letzten zufälligen oder normalen Lernfrage endet die Runde im Startmenü.
- Im Modus "Falsche Fragen wiederholen" bleibt der Button "Richtige Antwort anzeigen" erhalten.
- Das Anzeigen der Lösung verändert keine Statistik.
